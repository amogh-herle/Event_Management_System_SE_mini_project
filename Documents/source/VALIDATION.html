1. Introduction

1.1 Purpose

This report records whether the delivered system, as it stands on the main branch, satisfies the requirements in Documents/SRS_DOCUMENT.pdf (20 functional requirements FR-001a to FR-010b and 7 non-functional requirements NFR-001 to NFR-007) and in Documents/SECURITY_DOCUMENT.pdf (SR-001 to SR-012). A requirement is Validated when every test case mapped to it passed, Partially validated when some passed and some failed or were only partly executed, and Not validated when no case could be run.

1.2 Scope

Functional behaviour, performance and concurrency, security controls, accessibility, recoverability and maintainability of the web application, its API and its PostgreSQL data store. Infrastructure that the project does not operate (TLS termination, managed encryption at rest, monthly uptime monitoring) is reported as not run.

1.3 References

  • Documents/SRS_DOCUMENT.pdf, Documents/SECURITY_DOCUMENT.pdf, Documents/SAD_DOCUMENT.pdf
  • Documents/TEST-PLAN_DOCUMENT.pdf and Documents/TRACEABILITY_MATRICES.pdf (case definitions and matrices)
  • docs/reports/test-run.txt, coverage-report.txt, live-api-test-run.txt (raw evidence)

2. Validation Approach and Environment

Cases are written at three levels: unit (UT), integration (IT) and system (ST), plus non-functional (NFT) and security (SEC) cases. They were executed three ways: automated (node:test suite run against the code and, for concurrency, a real PostgreSQL SERIALIZABLE transaction), live (scripts/test_fr*.ts calling the running HTTP API), and manual (UI walkthroughs for two cases that need a browser).

8. Conclusion and Sign-off

The functional scope agreed in the SRS is complete and validated. Access control, account lockout, session idle timeout, CSRF protection, audit logging, input handling and token security pass their security cases. Remaining risk is confined to latency at the SRS target of 500 concurrent users, the unrun usability study, backup/uptime operations, and TLS and encryption at rest, which depend on an environment the project does not run.
